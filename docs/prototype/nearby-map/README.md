# 原型：附近柜机地图页

> **PROTOTYPE / throwaway** —— 回答 ticket「附近柜机地图页设计」的布局与状态问题。
> 不并入 `miniprogram/`，不改业务代码。验证完的 decision 由 map 记录，原型本身留在 `prototype/nearby-map` 分支。

## 结论（待选）

三个结构不同的变体，等选中一个（或从每个里偷一部分）后收口：

- **A · 地图优先 + 卡片轮播**：地图几乎满屏，顶部浮动搜索，底部单卡轮播，列表是抽屉。
- **B · 上下分屏**：206px 地图带 + 列表常驻，点列表定位 marker，地图失败塌成一行提示。
- **C · 目录优先**：列表按可用状态分组，地图收进页头按钮，全屏覆盖打开。

**倾向 B**：地图与列表同时在场，能比较 2–3 个站点；iOS 同层渲染失败时只塌一条，列表原地不动。
A 的地图观感最强，但卡片压在原生地图组件上风险最高，且一次只能看一个站点；C 最稳，但「附近」看起来像普通列表，弱化了地图承诺。

> 下面的内容与截图保留为比较记录。等选定后重跑状态图，并把结论写进本文件顶部。

## 这个原型回答什么

- **顶部搜索**：搜站点（名称 / 地址），不是搜柜机；搜索必须带 `city`，城市由用户手选。
- **地图**：marker 只落在有坐标的站点；颜色 = 站点可用状态；选中放大 + 名称 callout；定位按钮只在有授权时出现。
- **底部站点卡**：站点名、可用状态、距离、营业时间、地址、四档余位、柜机位置、导航。多站点时：A 轮播 / B、C 列表。
- **定位授权**：进入页面不自动弹窗；点定位按钮才 `wx.getLocation`；拒绝后城市 + 列表，距离整体隐藏。
- **列表切换**：A 有「地图 / 列表」切换；B 不切换（两个都在）；C 页头进地图。
- **空态**：附近无柜机、搜索无结果、定位失败、网络失败，各自独立。

## 三个变体

| | A · 地图优先 | B · 上下分屏 | C · 目录优先 |
|---|---|---|---|
| 首屏主角 | 地图 | 地图带 + 列表 | 列表 |
| 一屏可比站点 | 1 | 约 2.5 | 约 3.5 |
| 地图失败 | 自动打开列表抽屉，首屏空 | 地图带塌成一行，列表不变 | 主路径不依赖地图 |
| 定位被拒 | 城市视图 + 隐藏距离 | 地图带保留 + 隐藏距离 | 结构不变，只隐藏距离 |
| 主要风险 | 原生组件上叠卡片；比较成本高 | 地图表达力有限 | 地图承诺弱 |

## 共用裁决（不随布局改变）

1. **搜索 = 站点**。placeholder「搜索站点名称或地址」；结果行是站点，不是柜机。`city` 永远在搜索框里，点城市开选择器（数据源 `/nearby/cities`）。搜索忽略半径，城内按服务端排序。
2. **距离只格式化**。`distanceMeters` 为 `null` 时**整行不显示距离**（不是 `—`、不是「未知」）；0 是合法值；不加「步行」。
3. **站点卡的事实层**：站点名 / 可用状态 / 距离（有则）/ 营业时间（`businessHours` 缺则整行不渲染）/ 地址 / 四档余位 / 柜机位置（`lockers[].position`）/ 导航。
4. **没有「查看柜机」CTA**。响应不下发 `lockerId`，点 marker 也不进柜机页；唯一动作是「导航」（`wx.openLocation`）。站点缺坐标时不出现导航按钮。
5. **不写容量与示例物品**。后端没有尺寸字段，只写档名 + 余位；相对大小只靠数字，不编「可放 28 寸行李箱」。
6. **定位不自动请求**。进入页面只显示定位按钮；点击才 `wx.getLocation({type:'gcj02'})`。拒绝后不再弹窗，引导走 `wx.openSetting`（只能由点击触发）。未定位 = 城市 + 列表，不按距离排序。
7. **地图失败不是错误页**。列表照常可用：A 自动打开列表抽屉，B 地图带塌成一行提示 + 重试，C 无影响。地图重试用 `bind:error` / `bindrendererror` + 3–5 秒看门狗。
8. **可用状态只有三档**：可存件 / 已满 / 暂不可用。接口不区分离线与故障（`site.status` 不下发），所以**不做「离线 marker / 故障 marker」两种样式**，统一灰点。
9. **排序与分页归服务端**：`availability → distance(null 最后) → 站点名 → siteId`。客户端不重排；翻页按 `siteId` 去重；默认 `radiusMeters=3000`，空态可「扩大到 10 公里」。
10. **状态标签的对比度**：中性底 + 语义色边框 + ink 文字；语义原值只做边框 / 圆点，不当文字色。

## 状态矩阵

| state | 触发 | A | B | C |
|---|---|---|---|---|
| `ready` | 定位授权 + 有附近站点 | 地图 + 卡片轮播 | 地图带 + 列表 | 分组列表 + 地图入口 |
| `denied` | 用户拒绝 / 类目未批 / 系统定位不可用 | 顶部横幅「未定位」+ 城市 + 卡片隐藏距离 | 地图带保留 + 横幅 + 列表隐藏距离 | 列表隐藏距离，按站点名排序 |
| `maperr` | `bindrendererror` / 看门狗超时 | 地图区提示 + 自动开列表抽屉 | 地图带塌成 64px 提示行 | 地图入口打开后同样提示 |
| `empty` | 3 km 内 `list: []` | 空态：扩大到 10 公里 / 切换城市 | 同左 | 同左 |
| `search` | 点搜索框 | 全屏搜索层，城内结果 | 同左（覆盖列表） | 同左 |
| `noresult` | 关键词无命中 | 空态「没有找到「X」」 | 同左 | 同左 |
| `neterr` | 请求失败（自动重试一次后） | 整页「暂时连不上 / 请检查网络后重试」+ 重试 | 同左 | 同左 |
| `loading` | 首帧 | 骨架卡 + 地图占位 | 骨架卡 | 骨架行 |
| `citypick` | 点城市 | 底部城市选择器 | 同左 | 同左 |

截图里 `state-a-search` / `state-a-denied` / `state-b-maperr` / `state-empty` / `state-a-list` / `state-c-map` 是代表性状态；其余状态用 URL 复现。

## 文案（逐字）

| 位置 | 文案 |
|---|---|
| 搜索占位符 | 搜索站点名称或地址 |
| 搜索提示 | 在上海搜索「嘉里」 |
| 搜索无结果 | 没有找到「X」/ 换个关键词，或切换到其他城市试试 |
| 定位横幅 | 未定位 · 按站点名排序，不显示距离 / 开启定位 |
| 地图失败 | 地图没加载出来 / 站点列表仍可用 / 重试 |
| 空态 | 附近 3 公里内没有柜机 / 可以扩大范围，或换个城市看看 / 扩大到 10 公里 / 切换城市 |
| 网络失败 | 暂时连不上 / 请检查网络后重试 / 重试 |
| 站点卡 | 可存件 / 已满 / 暂不可用；柜机位置：…；只读信息 · 存件请扫柜机码；导航 |
| 列表头 | 附近 5 个站点 · 按可用状态、距离排序 |

## 待选定后要收口的细节

- 地图默认缩放级别（建议 14；「扩大到 10 公里」时 12）与聚合阈值（建议同屏 >15 个 marker 才聚合）。
- 搜索是边输边搜还是提交后搜（本原型画的是提交后）。
- 卡片轮播是否需要分页点（本原型用 `1 / 5` 计数）。
- 站点卡是否展示全部柜机位置（>2 台时只显示前两条 + 「共 N 台」）。
- 返回时是否保持地图中心与选中站点（建议保持页面栈内的状态，不落 storage）。

## 本原型不覆盖

- 视觉 token 最终值：等「视觉 token 消费级升级与 Vant 主题映射」定稿；这里按建议值画（`#008655` 主按钮、16px 卡片圆角）。
- 真实地图 / 定位 / 接口：地图是静态 SVG，站点是本地假数据，`state` 用 URL 手工切换。
- 分页与下拉刷新：一期单城 ≤100 一次取；超过再议。
- 动效：只保留骨架屏 shimmer。
- 远程下单 / 预约：附近柜机只读，写动作仍然只能从扫码开始。
