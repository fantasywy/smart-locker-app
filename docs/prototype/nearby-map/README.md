# 原型：附近柜机地图页（B · 上下分屏）

> **PROTOTYPE / throwaway** —— 回答 ticket「附近柜机地图页设计」的布局与状态问题。
> 不并入 `miniprogram/`，不改业务代码。验证完的 decision 由 map 记录，原型本身留在 `prototype/nearby-map` 分支。

## 结论（2026-10-22）

**选 B · 上下分屏**：206px 地图带 + 常驻站点列表。

- **不设「地图 / 列表」切换**：地图带始终在顶部，列表始终在下方；点列表卡 → 地图上对应 marker 高亮。
- **地图失败塌成一行**：`bindrendererror` / 看门狗超时后，地图带变成 64px 提示行（「地图没加载出来 / 站点列表仍可用 / 重试」），列表原地不动。
- **定位被拒只隐藏距离**：横幅「未定位 · 按站点名排序」，列表结构不变；不弹二次授权，只给「开启定位」入口（点击后 `openSetting`）。
- **全屏地图**是 B 里的次级入口（地图带右下角「全屏地图」），复用同一套 marker + 卡片轮播，不是另一个页面。
- **多站点用列表，不用轮播**：一屏能比较 2–3 个站点；轮播只保留在「全屏地图」模式里。

为什么不是 A / C：A 的地图观感最强，但卡片压在原生地图组件上风险最高，且一屏只能比较一个站点；C 最稳，但主路径完全不依赖地图，「附近」会看起来像普通列表。B 让地图与列表同时在场，是三者里唯一「地图失败时首屏仍然是完整的」的布局。

## 三个变体（比较记录）

| | A · 地图优先 | B · 上下分屏（选中） | C · 目录优先 |
|---|---|---|---|
| 首屏主角 | 地图 | 地图带 + 列表 | 列表 |
| 一屏可比站点 | 1 | 约 2.5 | 约 3.5 |
| 地图失败 | 自动开列表抽屉，首屏空 | 塌成一行，列表不变 | 主路径不依赖地图 |
| 定位被拒 | 城市视图 + 隐藏距离 | 地图带保留 + 隐藏距离 | 结构不变，只隐藏距离 |
| 主要风险 | 原生组件上叠卡片；比较成本高 | 地图表达力有限 | 地图承诺弱 |

## 这个原型回答的问题

### 顶部搜索

- 搜**站点**（名称 / 地址），不是柜机；结果行是站点。
- **城市永远在搜索框里**（「上海 ⌄」），点开选择器；数据源 `GET /api/app/v1/nearby/cities`。
- 搜索必须带 `city`（契约：`keyword` 必须带 `city`，城内搜索、忽略半径）。没有城市时先选城市。
- 搜索是「提交后搜」，不是边输边搜；结果页有「在上海搜索「X」」提示。
- 无结果：「没有找到「X」/ 换个关键词，或切换到其他城市试试」。

### 地图

- marker 只落在**有坐标**的站点；缺坐标的站点只在列表出现，且不显示距离、不出现导航按钮。
- marker 颜色 = 站点可用状态：绿（可存件）/ 琥珀（已满）/ 灰（暂不可用）。接口不区分离线与故障，**不做两种 marker**。
- 选中态：marker 放大 + 名称 callout；同屏只显示一个 callout。
- 默认缩放 14（覆盖 3 km）；「扩大到 10 公里」时 12。聚合阈值：同屏 >15 个 marker 才聚合（本原型 5 个，不触发）。
- 定位按钮只在有授权时出现；没有授权时顶部是「未定位」横幅。
- 地图加载失败 → 见结论；3–5 秒看门狗兜底。

### 底部站点卡

- 事实层：站点名 / 可用状态 / 距离（有则）/ 营业时间（缺则整行不渲染）/ 地址 / 四档余位 / 柜机位置（`lockers[].position`）/ 导航。
- **没有「查看柜机」CTA**：响应不下发 `lockerId`，点 marker 也不进柜机页；唯一动作是「导航」（`wx.openLocation`）。
- **不写容量与示例物品**：后端没有尺寸字段，只写档名 + 余位。
- 卡底一行「只读信息 · 存件请扫柜机码」——本页不产生写动作。

### 定位授权

- 进入页面**不自动请求**；用户点定位按钮才 `wx.getLocation({type:'gcj02'})`。
- 拒绝后不再弹窗；引导只能由点击触发 `wx.openSetting`。
- 未定位 = 城市 + 列表：不显示距离、不按距离排序（服务端退化为「可用状态 → 站点名 → siteId」）。

### 列表

- 不设地图/列表切换；列表常驻。
- 排序与分页归服务端（`availability → distance(null 最后) → 站点名 → siteId`），客户端不重排；翻页按 `siteId` 去重；默认 `radiusMeters=3000`。

### 空态

四种分开：附近无柜机（扩大到 10 公里 / 切换城市）、搜索无结果、定位失败（横幅，不是空页）、网络失败（复用全局「暂时连不上 / 请检查网络后重试」）。

## 状态矩阵

| state | 触发 | B 的表现 |
|---|---|---|
| `ready` | 定位成功 + 有站点 | 地图带 + 列表，按距离排序 |
| `denied` | 拒绝授权 / 类目未批 / 系统定位不可用 | 横幅「未定位」+ 隐藏距离 + 按站点名排序 |
| `maperr` | `bindrendererror` / 看门狗超时 | 地图带塌成 64px 提示行，列表不变 |
| `empty` | 3 km 内 `list: []` | 空态：扩大到 10 公里 / 切换城市 |
| `loading` | 首帧 | 地图无 marker + 3 张骨架卡 |
| `search` | 点搜索框 | 全屏搜索层，城内结果 |
| `noresult` | 关键词无命中 | 空态「没有找到「X」」 |
| `neterr` | 请求失败（自动重试一次后） | 「暂时连不上 / 请检查网络后重试」+ 重试 |
| `citypick` | 点城市 | 底部城市选择器 |
| `map` | 点「全屏地图」 | 全屏地图 + marker + 卡片轮播 |

截图在 `shots/b-*.jpg`（390×844 @2x）；A / C 的对比图保留为 `shots/option-*.jpg`。

## 实现时要收口的细节

- 地图缩放：默认 14 / 10 km 时 12；聚合阈值同屏 >15。
- 城市选择器还要补：搜索、关闭按钮、最近站点城市作建议。
- 站点卡柜机位置 >2 台时只显示前两条 + 「共 N 台」。
- 从全屏地图返回时保持地图中心与选中站点（页面栈内状态，不落 storage）。
- 主按钮 `#008655`、卡片圆角 16、阴影取值按「视觉 token 消费级升级与 Vant 主题映射」定稿为准。

## 本原型不覆盖

- 视觉 token 最终值（等 #49）。
- 真实地图 / 定位 / 接口：地图是静态 SVG，站点是本地假数据，`state` 用 URL 手工切换。
- 分页与下拉刷新：一期单城 ≤100 一次取。
- 动效：只保留骨架屏 shimmer。
- 远程下单 / 预约：附近柜机只读，写动作仍然只能从扫码开始。
