已选：B · 上下分屏（2026-10-22）

附近柜机地图页：选中的上下分屏

地图带 + 常驻列表：点列表定位 marker，地图失败塌成一行，定位被拒只隐藏距离。 A / C 保留为比较记录。真实入口： phone.html?view=B&state=ready|denied|maperr|empty|loading|neterr|search|noresult|citypick|map。

三个变体在争什么

不是配色差异：地图占多少、列表在哪、主操作是什么，三者互相不同意。

维度A · 地图优先B · 上下分屏C · 目录优先
首屏主角地图（几乎满屏）地图带 + 列表各占一半列表（地图收在页头按钮后）
一屏能比较几个站点1（轮播）约 2.5约 3.5，按可用状态分组
地图的价值找方向、看密度空间索引：点列表 → 地图定位一次性查看，非主路径
iOS 同层渲染失败时地图不可用 → 自动切列表抽屉，首屏是空的地图带塌成一行提示，列表原地不变主路径本来就不依赖地图
定位被拒时地图退成城市视图，卡片隐藏距离地图带保留，列表隐藏距离列表直接按站点名排序
主要风险卡片压在地图原生组件上；一次只看一个地图只有 206px，密度信息有限「附近」看起来像普通列表

B 的状态矩阵

状态由 ?state= 切换；截图均为 390×844 @2x。

本原型确定的

  • 地图带 + 列表常驻，不设地图/列表切换
  • 地图失败塌成一行提示，列表不受影响
  • 定位被拒：横幅 + 城市 + 列表，距离整体隐藏
  • 站点卡的事实层与文案（无「查看柜机」）

本原型不回答

  • 视觉 token 最终值（等 #49；这里按建议值画）
  • 真实地图与定位（用静态 SVG 模拟）
  • 分页与滚动加载（一期按单城 ≤100 一次取）
  • 动效（只保留骨架屏 shimmer）
