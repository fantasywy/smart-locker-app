# Research findings（AFK 事实底稿）

**为什么落在这里而不是 `.scratch/`**：`.scratch/` 按仓库约定是 throwaway，而 findings 是**已关闭 D 票裁决的证据链** —— D1–D5 的每条结论都指向这里。放进 `docs/` 才能跟 repo 一起 diff、review、长期存活。

> ⚠️ 历史上 findings 曾同时存在于一次性分支 `research/r*` 与 `.scratch/smart-locker-app/research/`，**两处会出现漂移**（例如 R1 的 `.scratch/` 副本一度停在 511 行，仍把 `13.16` 记为「未明确」，与下游 D4 的更正结论**直接矛盾**）。**自 2026-09-22 起，本目录为唯一事实源**，分支仅保留为历史。

## 约定

- 本目录**只写事实，不写设计裁决** —— 裁决住 `docs/spec/`。
- 每条断言必须带可核验的出处（`file:line`）。
