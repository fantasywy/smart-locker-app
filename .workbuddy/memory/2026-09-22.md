### 踩坑与工具修正

- **`gh issue view --json blockedBy` 的 jq 用法**：`blockedBy` 是**数组**，用 `"\(...)"` 插值会报 `expected an object but got: array`；**正确**是用 `[.state, ([.blockedBy[] | select(.state=="OPEN")] | length)] | @tsv` 这类数组构造。
- **REST 更稳**：`gh api repos/o/r/issues/N --jq '.issue_dependencies_summary.blocked_by'` —— 但本次 graphql/rest 出现零散 `unexpected EOF`，**重试一次即成功**（同一沙箱隧道抖动的老毛病，见 09-21 记录）。
- **`git checkout` 跨分支时被在用的文件锁住**：报 `unable to unlink ...: 设备或资源忙`（编辑器/预览持有句柄）。**解法**：`git checkout <target> -- <path>` 先把内容取回，再切分支；`git stash pop` 恢复临时改动。文件内容未受损（事后 `wc -l` 校验 235 行完好）。
